# Before writing OMBS copy, check the data

**Rule:** any framework name, count, or grade-band claim in narration, marketing
copy, or docs must be verified against `v0.1.0/crosswalks.json` and
`v0.1.0/standards.json` first.

**Why:** the obvious "K-12 standards" boilerplate (NGSS / CCSS / **CSTA**) is
wrong here — there is no CSTA crosswalk. The crosswalked frameworks are NGSS
Engineering Design, ISTE Students 2024, P21 4Cs, Agency by Design, and CCSS ELA
Writing. A promo script written from the obvious assumption had to be
re-recorded.

**How to apply:** crosswalk coverage is also uneven per code — an anchor code
shown on screen next to a framework badge may have no mapping to that framework
(e.g. `S.DF` has NGSS and ISTE mappings but no CCSS one). Either pick a code
that really is mapped, or present the crosswalk row at framework level
(name + mapping count) rather than implying a per-code link.
